youtubeUploader

Herramienta personal para publicar vídeos en el canal de YouTube Nuestros Relatos.

youtubeUploader es un pequeño programa que se ejecuta en el ordenador del propietario del canal. Usa los servicios de la API de YouTube (YouTube API Services) para subir los vídeos y shorts del propio canal, con su título, descripción, miniatura, lista de reproducción y fecha de publicación.

No es un servicio público: no tiene usuarios externos, no se vende y solo accede al canal de su autor, con el permiso que este concede a través de Google.

Al usar youtubeUploader se aceptan las Condiciones de servicio de YouTube.

youtubeUploader is a personal, single-user tool that runs on the channel owner's computer and uses YouTube API Services to upload videos and Shorts, with their metadata and thumbnails, to the owner's own YouTube channel. It is not offered to third parties. By using it you agree to the YouTube Terms of Service.
